# Theme demonstration
Audience: users choosing a Presenter theme.
Purpose: demonstrate native typography, cards, charts, code and speaker notes.
Source: repository format specification and implemented renderer capabilities.
The chart values are illustrative, not measured product metrics.
Plan: opening statement; audience and speaker workflow; sample chart; XML example;
an asymmetric 2:1 grid with padded cards, a spanning heading, and a horizontal footer.
All slides use explicit stack/grid/border trees; no preset layouts or automatic text scaling.
